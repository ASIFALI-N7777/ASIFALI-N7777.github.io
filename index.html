03 — Projects Three case studies, problem first.

Projects

Each of these started from a problem someone already had — a dataset nobody trusted, a classroom where decline surfaced too late, a ration shop where the paperwork couldn't say who collected what.

Sales Data Analysis Pipeline

ExcelPower BI / DAX PythonPowerShellSQL

An end-to-end pipeline that turns a deliberately dirty 10,000-row sales extract into a KPI dashboard you can defend line by line.

Problem

Real ERP exports arrive broken — duplicate postings, three date formats in one column, currency stored as text, blank prices, region names spelled four different ways. Any dashboard built on that is confidently wrong.

The decision that mattered

Every column of the clean layer is a live formula reading from the raw sheet — nothing pre-computed in Python. It costs performance and buys something better: a reviewer can click any cell and see why that row was kept, corrected or dropped.

What I built

A three-stage pipeline — raw extract generation, a formula-driven cleaning layer, and dashboard assembly. A deterministic SUMIFS/AVERAGEIFS layer sits between the pivots and the charts so a visual doesn't break when someone expands a pivot field.

Outcome

DAX measures for Total Sales, Profit % and YoY Growth; five PivotTables on a shared cache; three slicers; and a loss watchlist showing where margin is leaking. The monthly refresh is re-run, not rebuilt.

Cognitive Drift Detection

Published · IJRTI 2026
Machine LearningPython Learning Analytics

A web-based system that flags a student's cognitive drift while it is still recoverable — final year project, published as a peer-reviewed paper.

Problem

Academic decline gets noticed at assessment time, once the student has already fallen behind. The behavioural signals precede it by weeks — they're in the activity data, nobody is watching them.

Approach

Monitor learning behaviour and apply machine learning classification to sort students into Normal, Early Drift and High Drift — turning a continuous signal into three states a teacher can act on.

What I built

The classification pipeline and the dashboards that visualise behavioural trends over time, so the output reads as a name to check on rather than a model score.

Outcome

Published as “Behaviour Based Cognitive Drift Detection Framework for the Classroom Learning Environment” in the International Journal for Research Trends and Innovation, 2026.

Smart Ration Distribution

First Prize · National 2025
IoTAutomation Public Systems

A digitised public distribution workflow that makes every ration release traceable, and duplicate claims structurally impossible.

Problem

Ration shops run on paper. That leaves room for corruption, duplicate claims against one entitlement, and collection by someone who isn't the beneficiary — with no record that can prove any of it.

Approach

Ration is dispensed only after the beneficiary's unique ID card is scanned, which removes the discretionary step where most leakage occurred. Every dispense writes a traceable record.

Why duplicates fail

The entitlement is already marked against that beneficiary for the period, so a second claim has nothing to draw against. Not a policy — a data constraint.

Outcome

First Prize at a national-level hackathon, 2025.
