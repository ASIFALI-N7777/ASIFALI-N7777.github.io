Cognitive Drift Detection

Machine Learning Published · IJRTI 2026
PythonFlask Isolation ForestK-Means

A Flask web application that spots a student drifting while there is still time to do something about it. My final year project, and a published paper.

HTML 55.5% Python 38.4% CSS 6.1%
Problem

Academic decline gets noticed when the marks come in — by which point the student has already fallen behind. The behavioural signal is there weeks earlier; nobody is watching it.

Approach

Analyse student learning behaviour with Isolation Forest for the outliers and K-Means for the groupings, then sort students into Normal, Early Drift and High Drift — turning a continuous signal into three states a teacher can act on.

What I built

The Flask application end to end: the detection pipeline, the performance monitoring, the analytics views, and personalised learning recommendations — so the output reads as a name to check on, not a model score.

Outcome

Published as “Behaviour Based Cognitive Drift Detection Framework for the Classroom Learning Environment” in the International Journal for Research Trends and Innovation, 2026.

Smart Ration Distribution

IoT First Prize · National 2025
Connected hardwareAutomation Public systems

A digitised public distribution workflow that makes every ration release traceable, and duplicate claims structurally impossible.

Problem

Ration shops run on paper. That leaves room for corruption, duplicate claims against one entitlement, and collection by someone who isn't the beneficiary — with no record that can prove any of it.

Approach

Ration is released only after the beneficiary's unique ID card is scanned, which removes the discretionary step where most leakage happened. Every release writes a record.

Why duplicates fail

The entitlement is already marked against that beneficiary for the period, so a second claim has nothing to draw against. Not a policy — a data constraint.

Outcome

First Prize at a national-level hackathon, 2025.

Sales Data Analysis

Data & BI
ExcelPower BI / DAX PythonPowerShell

A pipeline that turns a messy sales extract into a dashboard you can defend line by line.

PowerShell 57% Python 37.7% Other 5.3%
Problem

Real exports arrive broken — duplicate postings, three date formats in one column, currency stored as text, blank prices, region names spelled four ways. Any dashboard built on that is confidently wrong.

The decision that mattered

The cleaning layer is live formulas reading from the raw sheet, not values pasted in. It costs performance and buys something better: anyone can click a cell and see why that row was kept, corrected or dropped.

Outcome

Cleaned 10,000+ order lines, then DAX measures for Total Sales, Profit % and Year-over-Year Growth, with pivot tables and slicers so people can answer their own questions without asking me.
