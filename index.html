Sales Data Analysis Pipeline

ExcelPower BI / DAX PythonPowerShellSQL

An end-to-end pipeline that turns a deliberately dirty 10,000-row sales extract into a KPI dashboard you can defend line by line.

Defects in the raw extract, and how each was handled
DefectResolution
Duplicate postings MATCH first-occurrence test drives a duplicate flag
Three date formats DATE / DATEVALUE / SEARCH — locale-independent parsing
Currency stored as text SUBSTITUTE + VALUE conversion to number
Blank prices XLOOKUP recovery against the product master
Region aliases Alias-to-canonical mapping table, joined on lookup
Cancelled & returned rows Nested IF rules that record why a row was excluded
The decision that mattered

Every column of the clean layer is a live formula reading from the raw sheet — nothing pre-computed in Python. It costs performance and buys something better: a reviewer can click any cell and see why that row was kept, corrected or dropped.

Stability

A deterministic SUMIFS/AVERAGEIFS layer sits between the pivots and the charts, so a visual doesn't break the moment someone expands a pivot field.

Outcome

DAX measures for Total Sales, Profit % and YoY Growth; five PivotTables on a shared cache; three slicers; and a loss watchlist showing where margin is leaking. Three scripts rebuild the whole thing — the monthly refresh is re-run, not rebuilt.

Cognitive Drift Detection

Published · IJRTI 2026
Machine LearningPython Learning Analytics

A system that flags a student's cognitive drift while it is still recoverable — final year project, published as a peer-reviewed paper.

The gap

Academic decline gets noticed at assessment time, once the student has already fallen behind. The behavioural signals precede it by weeks — they're in the activity data, nobody is watching them.

Approach

A web-based system that monitors learning behaviour and applies machine learning classification to sort students into Normal, Early Drift and High Drift — turning a continuous signal into three states a teacher can act on.

Delivered for teachers, not for me

The dashboard surfaces who crossed a threshold this week, so the output reads as a name to check on rather than a model score.

Smart Ration Distribution

First Prize · National 2025
IoTAutomation Public Systems

A digitised public distribution workflow that makes every ration release traceable, and duplicate claims structurally impossible.

Approach

Ration is dispensed only after the beneficiary's ID card is scanned — which removes the discretionary step where most leakage occurred. Every dispense writes who, what, when and which shop.

Why duplicates fail

The entitlement is already marked against that beneficiary for the period, so a second claim has nothing to draw against. Not a policy — a data constraint.
